The module groups three independent assets at the repository root: `scripts/run-migrations.mjs` is an ESM entry point that bootstraps a PostgreSQL connection via `pg.Pool` and `drizzle-orm/node-postgres`, loads optional env vars from a local `local.env` file (skipped in development when `DATABASE_URL` is missing), and applies migrations from the sibling `drizzle/` directory. `public/preview-manage-campaigns.html` is a self-contained, inline-styled static page used to visually mock the campaign management dashboard without running the server. `utils/utils.ts` exports a single `cn(...)` helper that composes `clsx` and `tailwind-merge` to resolve conflicting Tailwind classes — this is the only code artifact consumed by other parts of the application.
