Two-file module under `src/db/` plus Drizzle migration artifacts under `drizzle/`. `schema.ts` declares five `pgTable` definitions (`campaigns`, `campaignMembers`, `vacancies`, `marketListings`, `engagementEvents`) using Drizzle's `pg-core` column types, with foreign-key relationships (e.g. `campaignMembers.campaignId` references `campaigns.id` with cascade delete). `client.ts` is a server-only entry that loads `DATABASE_URL` from environment or a local `.env` file, creates a shared `pg.Pool` and a Drizzle `db` instance cached on `globalThis` to prevent re-initialization across hot reloads, and runs an `ensureDatabaseSchema()` bootstrap that executes raw `CREATE TABLE IF NOT EXISTS` DDL for all tables on startup. The `drizzle/meta/_journal.json` and `0000_init.sql` snapshot represent the initial migration state managed by Drizzle Kit. Consumers import `db` and the exported table schemas from this module; no query logic lives here — it exposes only the typed connection and model definitions.
