Three sibling Next.js Route Handlers under `src/app/{offers,orders,cart}/page.tsx`, each marked `'use client'` so they run in the browser. Data is pulled from two shared sources: `@/context/NegotiationContext` for live negotiation sessions (`sessions`, `buyerRespondToOffer`, `sellerRespondToOrder`, `finalizeNegotiation`) and `@/hooks/useNotification` for persisted `orders`/`offers`. Each page maps that raw data into a domain-specific list (active offers grouped by session, unique latest order per `cardId`, or static cart items) and renders them via reusable presentational cards (`OfferCard`, `OrderCard`, `BuyerCard`). Actions are wired to context dispatchers and accompanied by side effects such as `recordOfficeEvent` for activity logging. The cart page currently uses an in-memory fallback dataset rather than live state, acting as a placeholder UI.
