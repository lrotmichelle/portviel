The module follows Next.js App Router conventions under `src/app/office/`, where each subdirectory maps to a route segment. `page.tsx` is the root Office dashboard that composes a shared `OfficeSidebar` (from `@/components/office/`) with an `OfficeOverview` placeholder component. Sub-routes `discover/page.tsx` and `market/page.tsx` are self-contained client components (`'use client'`) that fetch data from `/api/discover` and `/api/market` respectively via `fetch`, render lists of jobs or market cards, and persist user actions through `recordOfficeEvent` in `@/lib/office-history`. Each sub-route embeds its own sidebar navigation linking across the Office workspace (`/office`, `/office/discover`, `/office/campaign`, `/office/market`, `/office/cv`, `/profile`). Shared layout concerns (sidebar, dark theme styling) are kept outside this scope in `@/components/office/`, keeping these pages focused on route-specific UI and state.
