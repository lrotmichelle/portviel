The module is the Next.js App Router entry point for the entire application. `layout.tsx` defines the `RootLayout` component that sets document metadata (title, description), imports `globals.css`, and composes a persistent chrome: a top `Navbar`, an expanding `<main>` slot for child routes, and a bottom `Footer`. It also wraps all children in `NotificationProvider` and `NegotiationProvider` from `@/context`, establishing app-wide React context at the root level. `page.tsx` renders the default home route as a standalone landing section. `globals.css` configures Tailwind v4 via `@import "tailwindcss"`, declares dark-theme CSS custom properties (`--background`, `--foreground`) mapped into Tailwind's `@theme inline` namespace, and registers reusable keyframe animations (`flipDown`) plus cross-browser number-input spinner suppression scoped to `.campaign-modal`. Dependency direction flows outward only: this module depends on `@/components/layout/*` and `@/context/*` but exposes no API of its own.
