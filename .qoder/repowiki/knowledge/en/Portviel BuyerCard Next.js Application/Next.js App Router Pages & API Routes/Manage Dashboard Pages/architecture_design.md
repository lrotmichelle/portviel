Each subdirectory under src/app/manage/ (adverts, campaigns, listings, vacancies) is a Next.js App Router route exporting a default 'use client' component that renders a dark-themed management UI. Data loading is performed in the browser with useEffect + useState, calling the shared '/api/secure' endpoint and mapping the returned payload into local state; mutations (e.g., price updates, deletions in listings) are POSTed back to the same endpoint with a mode field identifying the operation. Navigation between manage pages and their public counterparts uses Next.js <Link>, and reusable UI such as CampaignModal is imported from @/components/layout. There is no server-side data fetching or shared layout file — each page self-contains its header, back-link, empty-state, and item card rendering.
