Built on Next.js App Router: each route (`/campaign-manager/manage`, `/campaign-manager/joined`) is exposed via a thin `page.tsx` that re-exports a client component from a sibling `.tsx` file (e.g. `manage/page.tsx` → `manage.tsx`). The `manage.tsx` component is the composition root — it fetches mock data via `generateMockCampaigns` from `@/lib/mockCampaigns`, derives aggregate state (pool, settled, debt), and composes child presentational components: `Wallet` and `RecentTransactions` (from `@/components/campaign-manager`), plus in-module tables `members.tsx` and `reminder.tsx`, and a `progress-bars.tsx` visualization that renders a `DonutChart` from `@/components/DonutChart`. The `joined` route currently renders a placeholder. All components are marked `'use client'` and styled with Tailwind CSS using a dark zinc palette with emerald accents.
