The `src/app/` directory is the Next.js App Router entry point: `layout.tsx` provides a single root layout wrapping every route with global providers, navbar, footer, and theme CSS; each subdirectory maps to a URL segment and contains either a `page.tsx` client component or an `api/<segment>/route.ts` server handler. Domain pages (`campaign`, `campaign-manager`, `manage`, `office`, `offers`, `orders`, `cart`) consume data exclusively through the sibling `api/` routes, which in turn call shared services/repos — keeping UI stateless on the client and centralizing persistence behind typed server endpoints. Cross-cutting concerns (auth via secure endpoints, event tracking, negotiation state) are injected by the root layout rather than duplicated per page.
