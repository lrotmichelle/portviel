Each subdirectory (`campaign-card`, `job-card`, `market-card`) implements a self-contained card component following a consistent internal layout: an `index.tsx` default export composes `Header`, `Content`, and `Footer` subcomponents plus one or two domain-specific modules (`budget-sentiment.tsx` for campaigns, `sentiment.tsx` for market). The index file owns all local state (e.g., join/exit toggles, counter-offer flow, cooldown timers) and passes data down via props; child components are presentational and receive only the fields they render. Cards consume shared types from `@/types/*` and external contexts/libraries — `MarketCard` reads negotiation session state via `useNegiationContext` and formats currency through `@/lib/currency/formatToUGX`. Styling is uniform dark-mode Tailwind with conditional classes driven by derived flags like `isPaused`, `isInactive`, `hasActiveOffer`, and `isMaxed`.
