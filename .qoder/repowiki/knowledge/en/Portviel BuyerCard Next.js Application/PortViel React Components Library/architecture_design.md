Components are organised by feature area under `src/components/` with no cross-imports between sibling folders; each folder is a self-contained feature (domain cards, transaction cards, layout shell, office dashboard, profile/CV, UI primitives) that can be imported independently by pages or routes. Shared visual building blocks live in `ui/` (Badge, Button, Popover) and are reused across card and dashboard components via Tailwind utility classes rather than a central theme layer. The `office/` sub-tree additionally ships its own `index.html` and `layout.tsx`, indicating it can be rendered as a standalone embedded dashboard page alongside the main app. All components are client-side React files (`*.tsx`) styled with Tailwind, keeping the bundle light by avoiding heavy third-party UI libraries.
