The module is a flat collection of React Server/Client components under `src/components/layout/` that compose the page chrome and in-page modals. `Navbar.tsx` (marked `'use client'`) renders the sticky header with navigation links, notification/cart badges driven by the shared `@/hooks/useNotification` hook, and a mobile dropdown menu; it depends on `@/components/ui/button` and `lucide-react` icons. `Footer.tsx` is a static server component that centralizes site metadata (social links, service routes, contact info) in a local data object and renders a responsive multi-column layout via Tailwind. `grid.tsx` is a pure presentational wrapper exposing a responsive `grid-cols-1/2/3` container used by parent pages to lay out cards. The four modal files (`advert-modal.tsx`, `campaign-modal.tsx`, `listing-modal.tsx`, `recruit-modal.tsx`) share an identical shape: each exports a default function component typed with an `isOpen | onClose | onPublishSuccess` prop interface, renders a fixed `z-50` backdrop when open, and posts form data to Next.js API routes (`/api/campaigns`, `/api/market`, `/api/discover`) with a hardcoded `x-user-id: demo-user` header, then invokes `onPublishSuccess` with the created item before closing. `campaign-modal.tsx` additionally reads/writes global finance state via `@/lib/finance` and formats currency through `@/lib/currency`. There is no internal sub-package structure — dependency direction flows outward only into shared UI primitives, hooks, and lib utilities.
