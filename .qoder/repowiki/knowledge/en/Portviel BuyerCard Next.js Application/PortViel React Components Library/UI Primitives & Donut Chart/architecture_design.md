The module is split into two scopes. Under `src/components/ui/`, each file (`badge.tsx`, `button.tsx`, `popover.tsx`) defines one composable primitive that renders via a plain HTML element or a lightweight `Slot` shim instead of pulling in Radix UI — styling is driven by `class-variance-authority` variants and composed with the shared `cn` utility from `@/lib/utils`. The `Popover` is a minimal client-context implementation using `React.createContext` to coordinate `open` state between `Popover`, `PopoverTrigger`, and `PopoverContent`, deliberately avoiding Radix's full stack. At the sibling level, `DonutChart.tsx` is an independent 'use client' component that draws a donut chart purely with SVG `<circle>` elements, `stroke-dasharray`/`stroke-dashoffset` for segment arcs, and CSS custom properties to map Tailwind color tokens onto stroke colors; it depends only on `@/lib/currency` for value formatting and has no peer dependencies.
