The module is organized around a single client-side orchestrator (`cv/index.tsx`) that owns `selectedTemplate` and `profileData` state and renders one of three template components (`cv-temps/cv1.jsx`, `cv2.jsx`, `cv3.jsx`) based on user selection. Each template component implements an identical contract: it receives `profileData`, `setProfileData`, `ImageUploadTrigger`, and `DynamicSectionsRender` props, reads `data` from `profileData`, and updates fields via a local `updateField(field, value)` helper that immutably merges into `prev.data`. Shared UI primitives live in `cv-temps/shared.jsx` (e.g. `EditableText`), which templates reuse for name, title, email, phone, and location inputs. Templates are styled as printable pages using fixed dimensions (`minHeight: '297mm'`) and CSS grid/flex layouts, and each leaves a `{DynamicSectionsRender}` placeholder so dynamic sections can be injected by parent code. The dependency direction is strictly one-way: `cv/index.tsx` → template components → `shared.jsx`; templates do not import each other.
