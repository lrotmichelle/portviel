The app follows a layered Next.js App Router layout: `src/app/` hosts per-domain page routes (campaign, campaign-manager, manage, office, market, discover, profile) plus an `api/` folder of server-side route handlers; both layers consume shared libraries under `src/lib/` and `src/types/`. The data layer lives in `src/db/` (Drizzle schema + client singleton) and is accessed from API routes and domain libs via the same DB instance. Cross-cutting UI state (negotiations, notifications) is provided through React Contexts in `src/context/` with corresponding hooks in `src/hooks/`, while reusable UI is isolated in `src/components/`. A single root layout (`src/app/layout.tsx`) composes providers and global styles consumed by all pages. Build/dev scripts in `package.json` run `scripts/run-migrations.mjs` before Next.js starts, ensuring the database schema is up to date across dev, build, and production.
